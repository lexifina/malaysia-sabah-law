## Dates

Each commit is dated at noon (Asia/Kuching) on the day the change took effect. The other dates, enacted and published, are trailers.

When a law gives no date of its own, the default rule applies: Version dates follow each version’s stated source evidence. When the official PDF gives the effective date of its latest amendment, that date is used for its current wording. The first published batch instead used the first day of each FOR REFERENCE ONLY reference month; those dates await an amendment-table audit. https://sagc.sabah.gov.my/?q=en/law-type/sabah-laws

## How the history is built

`tools/build.py` turns the corpus into this history in one pass: one commit per law, on the day it took effect. The same corpus always gives the same commit hashes. `tools/check_repo.py` reads every version back from git and compares it with the corpus. `tools/on.py` shows the law as it stood on any date. The corpus format is described in `tools/SCHEMA.md`.

## Decisions made by hand

- Date-basis metadata only. The act-specific source note controls its current-text date. Earlier published text and dates are not changed by this part.
- Current text only: Sabah Lawnet gives each law as one text stamped "FOR REFERENCE ONLY (<month> <year>)", with no earlier consolidated text online, so each law is one version ("oldest version available", first_law null), credited to the State Attorney-General's Chambers, not to an amending law. The stamp gives a month only, so the version is dated the first day of that month.
- The amendment notes printed in the text ("(Deleted by En. No. 11/2018)") stay as printed; they are not replayed as history.
- One file per section (per Article in the Constitution); the title block and long title are "000-title", and each Schedule its own file. Part and Chapter headings stand above the first section under them; each section file gives its heading on the line before the section text.
- Left out: the cover, the arrangement of sections or articles, the "FOR REFERENCE ONLY" stamp, the "Sabah Lawnet" watermark, page numbers, footnotes and the "List of Amendments" tables.
